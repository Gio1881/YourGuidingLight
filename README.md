# Your Guiding Light

A Scripture-centered meditation, prayer, and spiritual wellness application.

## Getting Started

This project has been copied from Still Waters and is ready for customization.

## Features

- Guided meditations with Scripture
- Prayer journal
- Bible reader
- Sleep meditations
- Morning reflections
- And more

## Setup

1. Update `package.json` with Your Guiding Light details
2. Customize branding and content
3. Deploy to GitHub Pages or your server
